# Supplementary: Variance, Std Dev, and Gaussians — quick refresher

Companion to `../06_expectation_variance_reparam.md`. The basic probability facts that file assumes you remember. Read this if any of the symbols (`σ²`, `N(μ, σ²)`, `z-score`) feel hazy.

## Variance and standard deviation

### Variance

```
Var(X) = E[(X - E[X])²] = E[X²] - E[X]²
```

The expected squared distance from the mean. Always ≥ 0. Units are "input-units squared" — if `X` is in meters, `Var(X)` is in m². That's why we use std for human-readable spread.

### Standard deviation

```
σ = std(X) = √Var(X)
```

The square root, back in the original units. *The* number to report when describing "spread."

### Properties to know cold

For any constants `a, b` and random variables `X, Y`:

```
Var(aX + b) = a² Var(X)              # shifts don't matter, scales square
Var(X + Y) = Var(X) + Var(Y)         # IF X ⊥ Y (independent)
Var(X + Y) = Var(X) + Var(Y) + 2 Cov(X, Y)   # general case
```

The independence-then-add rule is doing massive work in DL — every "sum of i.i.d. random things scales as `√n`" argument uses it. Examples: dot products in attention (`Var ≈ d`, std `≈ √d`), gradient noise across a batch (`std ∝ 1/√batch`), random feature expansions.

### Sample variance vs. population variance

- **Population**: `(1/n) Σ (x_i - μ)²`. Used when you know the true mean `μ`.
- **Sample**: `(1/(n-1)) Σ (x_i - x̄)²`. Bessel's correction — divides by `n-1` because using `x̄` instead of `μ` underestimates spread.

In DL: doesn't really matter — `n` is always huge (batch sizes, dataset sizes), so `n` vs `n-1` is rounding error. PyTorch's `.var()` defaults to `n-1`; pass `unbiased=False` to get `n`. BatchNorm uses `n` (population), LayerNorm uses `n` over the feature dim — different conventions in different layers.

## The Gaussian / Normal distribution

The most important continuous distribution. Written `X ~ N(μ, σ²)`.

### Probability density function

```
p(x) = (1 / √(2π σ²)) · exp(- (x - μ)² / (2 σ²))
```

A bell curve centered at `μ`, with spread controlled by `σ`. `μ` is the **mean** (= the median = the mode); `σ²` is the **variance**.

```
              ╱╲
            ╱    ╲
           ╱      ╲
          ╱        ╲
        ╱            ╲
   ___╱                ╲___
  μ-2σ    μ-σ   μ   μ+σ    μ+2σ
```

### What "σ" controls

The peak height is `1 / √(2π σ²)`. Bigger σ → flatter, wider; smaller σ → taller, narrower. Total area is always 1.

### The 68–95–99.7 rule

For any Gaussian:
- `~68%` of mass within `μ ± σ` (one std)
- `~95%` within `μ ± 2σ`
- `~99.7%` within `μ ± 3σ`

Exceedingly rare to see anything beyond `4σ`. This is why "the activation hit `5σ` above its mean" is a meaningful "this isn't normal anymore" alarm.

## The standard normal — `N(0, 1)`

The Gaussian with `μ = 0` and `σ = 1`. The reference distribution everything gets standardized to.

```
p(z) = (1 / √(2π)) · exp(- z² / 2)
```

### Z-scores / standardization

Convert any Gaussian variable into standard form:
```
z = (x - μ) / σ        # x's distance from its mean, in std-dev units
```

A `z`-score of 2 means "2 standard deviations above the mean." This conversion is what BatchNorm and LayerNorm do per feature: subtract the mean, divide by the std.

### Why it's the reference

- Tables and CDF values are all reported for `N(0, 1)`.
- Any Gaussian can be reduced to the standard one via `z = (x - μ) / σ`.
- Sampling: `x ~ N(μ, σ²)` is generated by drawing `z ~ N(0, 1)` and computing `x = μ + σ z`. **This is the reparameterization trick.**

## Why Gaussians dominate DL

### 1. Central Limit Theorem (CLT)

The sum of many independent random variables (each with finite variance) tends toward Gaussian, regardless of the original distributions. So Gaussians describe the *aggregate* behavior of lots of small contributions.

In DL:
- A neuron's pre-activation is a sum of `d` weighted inputs → roughly Gaussian (assuming i.i.d.-ish inputs and weights).
- Gradient noise across a batch is a sum of per-sample gradients → roughly Gaussian.
- Init schemes (Xavier, Kaiming) draw from Gaussians because that's the maximum-entropy choice given a target variance.

### 2. Closed-form properties

Gaussians are uniquely friendly:
- **Sum of independent Gaussians is Gaussian**: `X ~ N(μ_X, σ_X²)`, `Y ~ N(μ_Y, σ_Y²)`, `X ⊥ Y` → `X + Y ~ N(μ_X + μ_Y, σ_X² + σ_Y²)`.
- **Linear transforms are Gaussian**: `aX + b ~ N(aμ + b, a²σ²)`.
- **Conditioning a multivariate Gaussian gives another Gaussian**.
- **KL between Gaussians has a closed form** — used in VAE losses, some RLHF KL penalties.

These properties make Gaussian assumptions analytically tractable when most other distributions force you into Monte Carlo.

### 3. The reparameterization trick (where this all lands)

Any sample from `N(μ, σ²)` can be written as `μ + σ · ε` with `ε ~ N(0, 1)`. The randomness lives in `ε` (which doesn't depend on params), and `μ`, `σ` are differentiable functions of params. This is *the* reason VAEs, diffusion models, and some policy-gradient variants work. See the primary file (`../06_expectation_variance_reparam.md`) for the gradient-estimation story.

## Multivariate Gaussian (briefly)

For vectors: `X ~ N(μ, Σ)` where `μ ∈ R^d` and `Σ ∈ R^(d × d)` is the **covariance matrix**.

```
Σ_ij = Cov(X_i, X_j) = E[(X_i - μ_i)(X_j - μ_j)]
```

Diagonal entries are individual variances; off-diagonal are pairwise covariances.

### Isotropic Gaussian

The special case `Σ = σ² I`. All components are independent with the same variance. The "round" Gaussian — its level sets are spheres.

In DL, this is the default for:
- Weight init (`N(0, σ²)` for each entry, all independent)
- Noise added during training (e.g. label smoothing, diffusion noise)
- Prior for VAE latent: `z ~ N(0, I)`

### High-dim concentration

Counterintuitive but important: in high dimensions, an isotropic Gaussian doesn't pile up around the origin. Almost all its mass concentrates in a thin **shell** at radius `‖x‖ ≈ σ √d`.

```
‖x‖² = Σ x_i²,   E[‖x‖²] = d σ²,   so ‖x‖ ≈ σ √d
```

This is why:
- Random embeddings are nearly orthogonal (see file `../../1.1_linear_algebra/06_projections_orthogonality.md`).
- Gaussian init produces activations that are well-conditioned in expectation.
- The `√d` in the attention scaling factor isn't arbitrary — it's the standard deviation of a sum of `d` i.i.d. unit-variance products.

## Symbol reference

| Symbol | Meaning |
|---|---|
| `μ` (mu) | mean |
| `σ` (sigma) | standard deviation |
| `σ²` | variance |
| `Σ` (capital sigma) | covariance matrix (in this context) — different from `Σ` as summation |
| `N(μ, σ²)` | univariate Gaussian with given mean and variance |
| `N(μ, Σ)` | multivariate Gaussian with mean vector and covariance matrix |
| `N(0, 1)` | standard normal |
| `ε` | typical name for a noise variable, often `N(0, 1)` or `N(0, I)` |
| `z` | a standard-normal sample, or a z-score `(x - μ) / σ` |
| `Cov(X, Y)` | covariance |
| `I` | identity matrix |

## Self-check

1. If `X ~ N(2, 9)` (note: variance, not std), what's `P(|X - 2| > 6)` roughly?
2. You stack 100 i.i.d. samples from `N(0, 4)` and average them. What's the distribution of the average?
3. Two independent vectors `q, k ~ N(0, I_d)`. What's `Var(<q, k>)`? What's `std(<q, k>)`? Why does this motivate the `1/√d` scaling in attention?
4. You initialize a weight matrix `W ∈ R^(d, d)` with entries from `N(0, 1/d)`. What's the expected variance of `Wx` for `x ~ N(0, I)`?
5. Write the reparameterization that lets you sample `x ~ N(μ, σ²)` while keeping gradients flowing through `μ` and `σ`.

## Answers (peek after attempting)

1. ~5%. `σ = 3`, so `6 = 2σ`, and the 95% rule says ~5% lies outside ±2σ.
2. `N(0, 4/100) = N(0, 0.04)`. Variance of the mean is `σ²/n`; std is `σ/√n = 2/10 = 0.2`.
3. `Var(<q, k>) = d` (sum of `d` independent products of unit-variance vars), so `std = √d`. Without the `1/√d` scaling, attention scores grow with `d` and saturate softmax.
4. `Var(Wx)_i = Σ_j W_{ij}² · Var(x_j) = d · (1/d) · 1 = 1`. So `Wx` stays unit-variance — exactly what good init aims for.
5. `x = μ + σ · ε` with `ε ~ N(0, 1)`. Now `μ` and `σ` are deterministic functions, so `∂x/∂μ = 1`, `∂x/∂σ = ε`, and gradients flow.
