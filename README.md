# Reviewing Deep Learning

A structured review curriculum for catching up on modern deep learning — written for an NLP practitioner who worked with RNNs, LSTMs, and BERT-scale Transformers and is getting current with the LLM / VLM era.

These are study notes, not a textbook: each topic file follows a *concept → why it matters → self-check → exercise* rhythm, and quantitative claims are verified by running them rather than quoted.

## Start here

- **[review_outline.md](review_outline.md)** — the 12-part curriculum and suggested pace. This is the entry point.
- **[NOTATION.md](NOTATION.md)** — symbols and conventions used throughout.
- **[ARCHITECTURE.md](ARCHITECTURE.md)** — one-page map of a modern decoder-only LLM, with every standard trick assembled.

Side-track: **[numpy_pytorch_schedule.md](numpy_pytorch_schedule.md)** plus [numpy_pytorch/](numpy_pytorch) and [pytorch_model_tour/](pytorch_model_tour) — runnable notebooks for rebuilding library fluency.
